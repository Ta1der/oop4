# Lab 4. Правило трёх

## Что делает класс
Matrix — динамическая матрица int с глубоким копированием.
Управляет памятью через правило трёх.

## Правило трёх
Если класс управляет ресурсом (памятью), нужно определить:
1. Деструктор — освобождает память.
2. Конструктор копирования — глубоко копирует данные.
3. Оператор присваивания — освобождает старую память и глубоко копирует новые данные.

## Реализованные методы
- `Matrix(const Matrix& other)` — конструктор копирования.
- `Matrix& operator=(const Matrix& other)` — с защитой от самоприсваивания.
- Приватные методы: `allocate`, `copyFrom`, `freeMemory`.

## Сборка (Windows, MinGW/g++)
g++ -std=c++17 -Wall -Wextra Matrix.cpp main.cpp -o lab4.exe
.\lab4.exe

## Что демонстрирует
1. a(3,4) заполняется случайными.
2. b = a — конструктор копирования. b.set(0,0,999) не меняет a.
3. c = a — оператор присваивания.
4. d = e = a — цепочка.
5. a = a — самоприсваивание, a не меняется.

## Почему деструктор не вызывается дважды
После правила трёх каждый объект владеет своей памятью:
- Конструктор копирования выделяет НОВУЮ память и копирует значения.
- Оператор присваивания освобождает старую память и тоже выделяет новую.
Никакие два объекта не смотрят на один data_.

## Особенности
- Пустая матрица (0×0): data_ == nullptr, copyFrom/freeMemory работают корректно.
- Защита: if (this == &other) return *this;.
- operator= возвращает Matrix& для цепочек.
- Рефакторинг: работа с памятью в трёх методах.
