# Lab 1. Класс Matrix

## Назначение
Класс Matrix — матрица целых чисел произвольной размерности.
Поля private, доступ через методы.

## Возможности
- Три конструктора: 0×0, единичная size×size, rows×cols с нулями.
- Деструктор освобождает память построчно в обратном порядке.
- get/set с проверкой индексов (std::out_of_range).
- inputFromKeyboard, fillRandom, print, sum.
- getRows, getCols.
- Проверка отрицательных размеров (std::invalid_argument).

## Сборка (Windows, MinGW/g++)
g++ -std=c++17 -Wall -Wextra Matrix.cpp main.cpp -o lab1.exe
lab1.exe

## Что демонстрирует
1. Создание четырёх матриц разными конструкторами.
2. Вывод m2, m3, m4.
3. m2 по формуле i*j.
4. m3 случайными числами.
5. Ввод m4 с клавиатуры.
6. Сумма m3.
7. Ловля исключений.

## Особенности
- Пустая матрица (0×0): память не выделяется, деструктор безопасен.
- Построчное выделение/освобождение памяти.
- explicit у конструктора с одним параметром.
- Конструктор копирования не реализован → копирование даёт двойное освобождение.
